고1 공통국어2 「학급 언어생활 사례 조사」 프로젝트(50분 × 3차시)의 수업 안내 정적 웹사이트입니다.

- 용도: 교실 대형 화면 강의(PPT 대용) · 학생 상시 참고 · 프로젝트 소개
- 구성: 조사 의뢰문 / 프로젝트 개요 / 차시별 흐름 / 활동 도구 / 안전 약속 / 자료실 / 참관 안내
- 콘텐츠 원고: `docs/CONTENT.md` (SSOT — 사이트 문구는 이 파일과 일치해야 함)
- 학습지 PDF: `files/` (차시당 A4 1장 × 3)
- 캐릭터·배경 이미지: `img/` (생성형 이미지)

## 관련 자료

- RED 카드 웹앱(Google Apps Script): 사이트 자료실 링크 참고
- 수업 설계 문서: 별도 작업 폴더(`_workspace/`)에서 관리
